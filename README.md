_# Social Media Addiction & Mental Wellbeing Analytics

## 📊 Project Overview
This project explores the impact of daily social media usage, screen time, and app notifications on user mental health and addiction levels. It features a fully interactive **3-Page Power BI Dashboard** built to uncover behavioral patterns and high-risk user segments.

## 🛠️ Tools & Technologies Used
* **Power BI**: Data modeling, custom DAX measures, and interactive UI design.
* **Power Query**: Data cleaning, handling missing values, and transformation (filtering the raw 1,500-row CSV down to 672 complete records for baseline analysis).
* **AI Visuals**: Key Influencers and Decomposition Trees for advanced diagnostics.

## 📈 Dashboard Structure & Key Pages
* **Page 1: Executive Overview**: High-level KPIs tracking total users, average daily screen time, and mental wellbeing scores.
* **Page 2: Behavioral Deep Dive & Root Cause Analysis**: Multi-variable root-cause analysis using a Decomposition Tree across platforms and demographics.
* **Page 3: AI-Powered Key Influencers**: Machine learning-driven insights identifying primary behavioral drivers of severe addiction levels.
